# My Dream Coding Project: StudyBuddy

## Project Overview
**StudyBuddy** is an app designed to help students plan their homework, track their study time, and stay motivated during tough weeks. It's built using **HTML, CSS,** and **JavaScript** - but one day, I want to turn it into a full mobile app.

---
## Project Goals
- Build a simple dashboard that tracks:
    - homework due dates
    - minutes studied each day
    - subjects that need extra practice
- Show encouraging messages using
    - ` console. log`
    - ```js
        if (minutesStudied >= 30) {
            console. log("Awesome work! You hit your goal today!");
        } else {
            console. log("Keep going, every minute counts!")
        }
